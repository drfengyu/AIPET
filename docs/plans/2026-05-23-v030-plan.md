## 推荐执行方案

### 第一阶段：桌宠核心（P0，~3 天）

```
Task 1: 透明浮动模式
  - 主进程：创建透明窗口 + WS_EX_LAYERED + 点击穿透
  - 渲染进程：透明背景渲染 Live2D
  - 设置面板：透明模式开关 + 透明度滑条
  - 拖拽：鼠标拖拽 reposition

Task 2: 迷你紧凑模式
  - 新增 CompactView 组件（仅角色 + 情绪点）
  - 切换按钮：全模式 ↔ 迷你模式
  - 边缘吸附：靠近屏幕边缘时半隐藏

Task 3: 记忆 2.0
  - AI 回复中提取 facts（正则/关键词）
  - localStorage 保存 facts 列表
  - 记忆面板：弹出式 UI 查看/删除 facts
  - 注入到 AI 对话上下文中
```

### 第二阶段：智能增强（P1，~2 天）

```
Task 4: AI 主动对话
  - 闲置计时器 → 触发 AI 问候
  - 时间段感知（早上/中午/晚上）
  - 可配置：开关/间隔

Task 5: 情绪日记
  - 每日对话情绪数据收集
  - 日记面板：按日期查看
  - AI 生成每日总结

Task 6: 系统事件响应
  - 监听系统时间变化
  - 简单规则引擎（深夜→困了、闲置→发呆等）
```

### 第三阶段：打磨（P2，~1 天）

```
Task 7: 纹理压缩 + 性能优化
Task 8: 表情面板 UI
Task 9: 代码清理
```

## 技术要求

| 功能 | 关键技术 |
|------|----------|
| 透明窗口 | `BrowserWindow` + `setBackgroundColor('#00000000')` + `setIgnoreMouseEvents()` |
| 点击穿透 | `win.setIgnoreMouseEvents(true, { forward: true })` |
| 拖拽 | 鼠标事件监听 + `win.setPosition()` IPC |
| 迷你模式 | 新组件 + `win.setSize()` IPC |
| Facts 提取 | AI 回复正则解析 + `localStorage` |
| 主动对话 | `setTimeout` / `setInterval` + AI 调用 |
| 情绪日记 | 每日 `cron` 触发 + AI 摘要生成 |
